图片格式转换

苹果手机拍的 heic 传到电脑或报名系统打不开？转成 jpg 就行。webp、png、gif 之间也能互转，一次选一堆一起处理。不上传，本地转。

拖图片进来，或者点一下选

支持 heic / heif / jpg / png / webp / gif / bmp，可以多选

    heic 首次转换会慢几秒：浏览器要先把苹果那套编码加载起来，一张之后后面就快了，别急。要是转出来是黑的，多半是那种带多帧的实况照片，试试点单张重转。

    什么时候需要转

    iPhone 默认拍 heic，体积小但很多政务系统、老邮箱、打印店不认，一律要 jpg。网页上存的图常是 webp，要放进 Word 或 PPT 就得转 png 或 jpg。png 转 jpg 会丢掉透明背景，自动补白底。
