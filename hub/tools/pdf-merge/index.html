PDF 合并与拆分

几个 PDF 想合成一份？或者一大份里只想要第 3 页到第 7 页？拖进来选一下就好。本地处理，文件不上传。

把 PDF 拖进来，或者点一下选

按添加顺序合并，进来还能上下调

    三种模式：合并是把多个 PDF 按顺序接起来；提取是从一个 PDF 里挑页，可以写 1-3,5,8-10 这种；每页拆开是把一份 PDF 拆成单页，一页一个文件，方便只看某一页或者单独发出去。

    常见用法

    简历加证书合成一份投递；合同附件接到正文后面；发票一个月几十张合一个报销；投标文件只留要求的章节。加密过的 PDF 会打不开，先用原密码解锁再处理。
