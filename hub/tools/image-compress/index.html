图片压缩到指定大小

系统让你传 20k 以内？压到那个数就行。设个目标大小，剩下的它自己试，画质尽量给你留住。文件不上传，全在浏览器里处理。

把图片拖进来，或者点一下选图

支持 jpg / png / webp / gif 截图，可以一次选多张

    怎么做到的：先在原尺寸上降画质试，还超就一点点缩尺寸，直到压进你要的那个 KB 数。所以 20k 的图会变小一些，这是物理规律，不是偷懒。

    这几种情况你可能还要用到

    考公报名照片一般 20k 以内、教师资格证 200k 以内、社保和政务系统常见 100k 或 500k 以内；投标和论文查重一般按 MB 卡，这个工具也能设。
